#  Proyecto 01 POO - 2do Semestre 2026
## Software a desarrollar:
Se crea una aplicación JAVA de un gestor de recetas de cocina.
Esta aplicación consta de una interfaz gráfica, y diferentes funcionalidades
entre estas agregar recetas, agregar ingredientes disponibles, agregar utensilios disponibles,
filtrado de recetas por ingredientes y utensilios, dificultad, etiquetas, etc.
Ademas de esto la aplicación cuenta con un sistema de guardado por lo que los datos
permanecen guardados en un archivo para asi poder cerrar la aplicación sin perder los contenidos.
